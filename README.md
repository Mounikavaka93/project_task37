# Meridian — Trading & Investment Platform

A modern, responsive trading UI built with React, Vite, Tailwind CSS, and React Router. All market data is static demo content — no backend required.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Routes

- `/` Cinematic entry
- `/home` Home
- `/markets` Market overview
- `/stocks` Equities
- `/portfolio` Holdings dashboard
- `/watchlist` Watchlist
- `/about` About
- `/login` `/signup` Demo auth
- `/privacy` `/terms` Legal
